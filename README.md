## Upload the original files

Download the complete original-assets package from the ChatGPT conversation:
`WILANY_GERMANO_GITHUB_READY.zip`

Extract that ZIP locally. In GitHub, click **Add file → Upload files**, then drag the entire `assets` folder with all subfolders intact. Commit to `main`. Preserve the file names exactly.

## Publish on GitHub Pages

At https://github.com/germanodesign/WilanyGermano/settings/pages :

1. Source: **Deploy from a branch**.
2. Branch: **main**.
3. Folder: **/(root)**.
4. Click **Save**.

The expected public address is:
https://germanodesign.github.io/WilanyGermano/

Do not claim the website is live until the Pages deployment succeeds and the images and Vimeo playback have been verified.
